# smart-lawn-sprinkler-automatic-system
Smart Lawn Sprinkler Automatic System  The Smart Lawn Sprinkler Automatic System is an IoT-based irrigation system designed to automatically water plants and lawns according to the moisture level of the soil. The main aim of this project is to save water, reduce manual effort, and provide proper irrigation to plants.
